# Bedside Magnetocardiography with a Scalar Sensor Array

## Overview

Iwata, Nguyen, Tharratt, Ruf et al. (MDPI Sensors, 2024) demonstrate a practical magnetocardiography (MCG) system using an array of scalar optically-pumped magnetometers (OPMs) without magnetic shielding, recording cardiac field maps from 30 volunteers.

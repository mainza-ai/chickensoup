# AQVolt26: High-Temperature r2SCAN Halide Dataset

## Overview

Kim, Wang, Singh, Sours, Agarwal, Nish, Abruzzo, Allam (SandboxAQ/NVIDIA, 2026) release a 26-temperature halide solid-state electrolyte dataset for universal ML potentials and solid-state battery research, enabling diffusion in ionic conductors.

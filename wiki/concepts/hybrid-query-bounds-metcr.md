# Hybrid-Query Bounds with Partial Input Control: Tight M-eTCR

## Overview

Hülsing, Kudinov, Majenz (Eindhoven/SandboxAQ/DTU, 2025) improve the security analysis of multi-target extended target collision resistance (M-eTCR) in the quantum random oracle model, providing tighter bounds with fewer reprogramming constraints for hash&sign PQC schemes.

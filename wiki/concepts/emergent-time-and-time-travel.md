# Emergent Time and Time Travel in Quantum Physics

Alonso-Serrano, Schuster, and Visser (2024) develop a toy model demonstrating that the famous paradoxa of time travel dissolve when time itself is understood as an emergent relational property rather than a fundamental background parameter.

## Core Argument

### The Problem of Emergent Time

- GR's closed timelike curves (CTCs) face logical contradiction arguments (grandfather paradox, bootstrap paradox)
- These arguments implicitly assume a fundamental, global time parameter
- Canonical quantum gravity (Wheeler–DeWitt) has no time at all: ˆH|Ψ⟩ = 0
- Page–Wootters formalism provides an operational substitute: time emerges from correlations between subsystems

### Page–Wootters Mechanism

- The "universe" H splits into clock (HC) and residual (HR) subsystems: H = HC ⊗ HR
- Total state |Ψ⟩ is a fixed energy eigenstate with no external evolution parameter
- Residual system evolution is defined **relative to** clock readings: conditional probabilities replace absolute time
- Time emerges from entanglement structure; not fundamental

### POVM-Based Time Observable

- Time operators face no-go results (Pauli, Unruh–Wald impossibility theorems)
- Positive operator-valued measures (POVMs) provide a workaround: a phase POVM on the harmonic oscillator rigorously defines periodic time
- Time eigenstates |θ⟩ are overcomplete but form a proper quantum observable via the POVM B₀ on [0, 2π)

### Time Travel Without Paradoxa

- Model: two coupled oscillators with WDW-like total-energy constraint (H_total = 0)
- Clock periodicity → periodic relational "time" → dynamical system returns to same state each period
- Satisfies Novikov's self-consistency conjecture automatically: the system **cannot** diverge because it's in a constrained energy eigenstate
- Paradoxa are preempted — there is no freedom to diverge from the self-consistent state

### Broader Implications

- GR counterarguments to time travel rely on specific notions of time (thermodynamic, causal, geometric)
- A quantum-gravity theory with emergent time may use different consistency criteria
- Distinct from CTC-based time travel: relational periodic dynamics is a fundamentally different mechanism

# A Gaussian Leftover Hash Lemma for Modules over Number Fields

## Overview

Albrecht, Felderhoff, Lai, Lapiha, Woo (KCL/SandboxAQ/Aalto/Royal Holloway, 2025) generalize the Gaussian LHL to modules over number fields with applications to lattice-based cryptography for hiding sensitive distributions in quantum reductions.

# Parallel DMRG Quarter petaFLOPS on DGX-H100

## Overview

Menczer, van Damme, Rask, Huntington, Hammond, Xantheas, Ganahl, Legeza (Wigner/SandboxAQ/NVIDIA/PNNL, 2024) report a hybrid CPU-multi-GPU DMRG implementation achieving 0.25 petaFLOPS on a single DGX-H100 node for strongly correlated quantum systems.

# Revisiting Key Decomposition Techniques for FHE

## Overview

Georgieva Belorgey, Carpov, Gama, Guasch, Jetchev (Tune Insight/Arcium/SandboxAQ/EPFL/IOG, 2023) simplify and generalize key decomposition for Ring-LWE FHE, decoupling decomposition from the RNS CRT structure and enabling faster, more generic FHE at large depth.

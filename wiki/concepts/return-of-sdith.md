# The Return of the SDitH

## Overview

Aguilar-Melchor, Gama, Howe, Hülsing, Joseph, Yue (SandboxAQ/Eindhoven, 2022) present a code-based signature scheme using the Syndrome Decoding in the Head (SDitH) approach with MPC-in-the-Head, producing practical signatures from the hardness of decoding random linear codes.

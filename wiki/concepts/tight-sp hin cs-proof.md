# A Tight Security Proof for SPHINCS+, Formally Verified

## Overview

Barbosa, Dupressoir, Hülsing, Meijers, Strub (University of Porto/INESC TEC/University of Bristol/Eindhoven/SandboxAQ/PQShield, 2024) formally verify the first tight security proof for SPHINCS+ (now standardized as SLH-DSA), fixing a flawed prior proof and enabling deployment with quantifiable security margins.

# Protecting Cryptographic Code Against Spectre Variants

## Overview

Arranz Olmos, Barthe, Chuengsatiansup, Grégoire, Laporte, Oliveira, Schwabe (MPI-SP/IMDEA/Arcium/SandboxAQ, 2024) formally verify protection of cryptographic code against Spectre-RSB and all known Spectre variants, enabling constant-time guarantees for post-quantum implementations.

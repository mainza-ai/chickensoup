# Scaling Lattice Sieves across Multiple Machines

## Overview

Martin R. Albrecht (KCL/SandboxAQ) and Joe Rowell implement BGJ1 and BDGL lattice sieving algorithms across multiple server nodes, demonstrating that exponential-memory sievers can be distributed with careful design. This directly enables SVP hardness assumptions underlying lattice-based PQC schemes.
